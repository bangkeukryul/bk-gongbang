① 기획 · 대본

주제를 쓰고 요청문을 복사 → AI에 붙여 넣고 보내기 → AI가 준 대본을 아래 칸에 붙여 넣기.

② 그림 (ChatGPT)

ChatGPT 대화창 하나에서 차례로 하세요. 먼저 인물·장소 그림을 만들고, 그다음 컷 장면 그림을 만들면 얼굴이 같게 나와요.
각 칸: 「📋 요청문 복사」 → ChatGPT에 붙여 넣기 → 그림을 길게 눌러 저장 → 「🖼 그림 넣기」.

③ 영상 (Google Flow)

컷마다 「✨ 영상 만들기」를 눌러 차례로 하세요. 영상이 없는 컷은 그림이 천천히 움직이는 장면으로 들어가요.

✨ 영상 만들기

⚠ Flow에서 꼭 이렇게 해야 내 그림이 그대로 움직여요
ⓐ 처음 한 번: 위쪽 ＋ 또는 업로드(⬆)로 ①에서 저장한 그림을 Flow에 올리기
ⓑ 입력 칸 왼쪽 아래 「＋」 → 목록에서 그 그림 누르기
ⓒ 입력 칸 안에 작은 그림이 붙었는지 꼭 확인
ⓓ 설정 칸에서 모델을 위에 적힌 것으로 · 세로 · 8초
ⓔ 「무엇을 만들고 싶으신가요?」에 ②의 프롬프트 붙여넣기 → →
ⓕ 다 되면 영상 누르기 → 다운로드
✖ 입력 칸에 그림이 안 붙은 채로 만들면 다른 사람 영상이 나와요.
